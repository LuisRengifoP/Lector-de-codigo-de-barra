Cargar el listado

Mejor el Excel (.xlsx) o el CSV del DMS. El texto del PDF pierde columnas y esas filas quedan en revisión.

Qué columnas se leen y qué se comprueba

Se esperan Código (el SKU de compras), Alterna (el código de barras), Descripción, u/e, Cajas, Precio Und, IVA y Precio Final. El proveedor se lee del encabezado de cada sección del reporte.

Formatos aceptados: Excel (.xlsx), CSV y el texto del reporte con las columnas conservadas (pdftotext -layout).

De cada fila se comprueba que Precio Und × (1 − Desc) × (1 + IVA) dé el precio final. Donde no da, la fila viene corrida de renglón y su código de barras puede no ser el de ese producto. Los cigarrillos y algunas bebidas no cuadran por el impuesto al consumo, que no sale en ninguna columna.

Pendientes de compras

Filas sin un código de barras usable. Cada una se resuelve escaneando el empaque.

Por qué no entran solas a la tabla

Son filas del listado que no se pueden guardar como producto escaneable: sin código de barras, con un número que no es un código de barras, o que el texto del PDF trajo incompletas.

Un código inventado no se nota nunca: nadie lo escanea y el producto figura como registrado. Por eso queda pendiente hasta que alguien lea el empaque de verdad.
